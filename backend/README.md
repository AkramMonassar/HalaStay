A modern, secure hotel management and online reservation system designed for Yemen & Saudi Arabia markets with multi-payment gateway support.

---

## 🌟 Features (Planned)

### For Guests
- 🔍 Search & filter hotels by city, price, amenities
- 📅 Real-time availability & instant booking
- 💳 Multi-payment methods:
  - 🇾🇪 Yemen: E-wallets (Meeza, Y-Cash, etc.) + manual code verification
  - 🇸🇦 Saudi: Mada, Apple Pay, Credit Cards (future integration)
  -  International: PayPal, Stripe (future)

### For Hotel Owners
- 🏨 Complete hotel & room management
- 📊 Booking dashboard with confirmation workflow
- 💰 Revenue reports & analytics

### For Admins
- ✅ Hotel approval system
- 👥 User & booking management
- 🌍 Country-specific payment configuration

## 🛠️ Tech Stack

### Backend
- **Laravel 11** – RESTful API
- **MySQL** – Database
- **Laravel Sanctum** – Authentication

### Frontend
- **Vue.js 3** – SPA Framework
- **Axios** – HTTP Client
- **Tailwind CSS / Bootstrap 5** – UI (TBD)

### Tools
- **Git & GitHub** – Version Control
- **Postman** – API Testing
- **Composer & NPM** – Package Managers
